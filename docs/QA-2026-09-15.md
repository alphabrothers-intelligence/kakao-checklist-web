## 모바일 저장 배치 오류 후속 수정

사용자 실기기에서 상단 축소·공백이 발생한 사례를 받아 저장 방식을 교체했다.

- SVG foreignObject를 통한 HTML 재렌더링 제거.
- DOM에서 측정한 글자 위치·배경·모서리·이미지를 Canvas에 직접 그린다.
- 오프스크린 화면의 viewport와 글자 자동 확대 비율을 고정한다.
- PNG: 390px 모바일 배치 × 3배 해상도. PDF: 1080px PC 배치 × 2배 해상도.
- 모바일 메모리를 위해 캔버스 면적 16MP 및 한 변 16000px 제한 적용. 초과 시 저해상도 파일 대신 오류를 안내한다.
- 모바일 제목은 의미 단위로 묶고, 단어 유지·균형 줄바꿈을 적용한다. 문제 아이콘과 본문을 두 열로 정렬한다.
- 테스트 608개·빌드 통과. Chrome과 WebKit 26.6에서 PC·모바일 화면 및 PNG·PDF 다운로드 통과.
- WebKit의 실제 다운로드 PNG에서 상단 축소·비정상 공백 없이 전체 내용과 캐릭터·글자가 표시됨을 육안 확인했다.
- WebKit은 데스크톱에서 실행한 Safari 계열 엔진 검사다. 사용자 휴대폰의 동일 증상 해결 여부는 배포 후 실기기 확인이 필요하다.

```sh
node scripts/verify-browser.mjs http://127.0.0.1:5180 --webkit
```

WebKit 산출물: `artifacts/browser-webkit/`.
